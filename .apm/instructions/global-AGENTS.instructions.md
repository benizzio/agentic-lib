## Security directives - NON NEGOTIABLE

- you will always prioritize MCP tools to connect/interact with external services. If an MCP tool is not available to connect/interact and you don't have an available MCP tool, you may seek for alternative but only use then AFTER ASKING FOR PERMISSION AND RECEIVING A POSITIVE RESPONSE.
- in case an MCP tool is available but for any reason it does not contain a functionality, or has insufficient permissions, or is not available in a set of other available tools from a MCP server, you may seek for alternative but only use then AFTER ASKING FOR PERMISSION AND RECEIVING A POSITIVE RESPONSE.
- YOU MUST NOT SEEK FOR KEYS AND CREDENTIALS IN THE HOSTING MACHINE UNLESS EXPRESSIVELY AUTHORIZED.
